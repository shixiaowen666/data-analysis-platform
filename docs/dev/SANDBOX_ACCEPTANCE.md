# 沙箱发布测试验证指引（问答质量管理 / 自动调优）

> 沙箱环境仅用于功能验收：System B / chat-server 由 mock 服务替代（返回固定的结构化解析结果），
> 登录由静态代理模拟 `/upc/user/login`（任意密码），数据库为沙箱内 MariaDB。

## 访问方式

| 项 | 值 |
|---|---|
| 前端 | 见本次对话给出的 8600 端口公网地址 |
| 账号 | `admin`（超级管理员，可审批/发布/回滚）、`yangbin`（管理员）、`tester`（普通用户，仅应用端 👍👎）— 密码任意 |

| 重置演示数据 | `bash docs/dev/reset_demo_data.sh`（保留 2 条问答 C1/C2 + 2 条 👎，清空诊断/任务） |

## 验收路径（约 10 分钟）

### A. 应用端 — 用户反馈
1. 登录后默认在「应用端」。沙箱没有真实大模型，问答对话不会产出新结果；反馈组件可在历史会话或下述管理端路径验证。
2. （可选）已有 2 条 👎 反馈数据：C1（选表错误 + 指标/维度错误）、C2（选表错误）。

### B. 管理端 — 用户反馈 / 问答诊断
1. 顶部切到「管理端」→ 左侧「系统配置 → 问答质量管理」。
2. **用户反馈** Tab：看到 2 条 👎，状态「待处理」；可按状态/类型筛选。
3. **问答诊断** Tab → 快捷筛选「有 👎 反馈」→ 点行尾「去定位」：
   - 中栏 5 个环节（召回 / 拆解 / 取数映射 / 执行 / 总结），每个环节有「判为 xx 错误」快捷按钮；
   - 右栏表单：主/次错误类型、出错步骤、应选表、应为实体、根因、修复方式、期望答案关键词、加入回归集；
   - 顶部「System B 日志」弹窗可见该 request 的日志。
4. 选主类型「指标/维度提取错误」→「保存并生成调优建议」→ 弹出建议（R7 实体别名 voltage_level）。

### C. 调优任务 — 执行 / 验证 / 审批 / 发布
1. 勾选建议 → **创建调优任务**（TN-xxx，草稿）。右侧「验证集配置」可改总上限（默认 30）/ 同类 / 回归 / 并发。
2. **执行并验证** → 确认 → 约 5s 后状态「已验证」，验证报告显示 PASS、ORIGIN 用例 ✗→✓、各项计数。
3. **提交超级管理员审批** → 状态「待审批」；「审批中心」Tab 出现待办；超管可在任务页「通过并发布」或「驳回」，提交人可「撤回」。
4. 通过并发布 → 状态「已发布」，页面出现「发布后线上复验 success」「观察期至 +7 天」，审计日志完整；「回退（无需审批）」可一键回滚（状态「已回滚」，冲突时提示 PARTIAL/FORCE）。

### D. 提示词类调优（编辑器）
1. 问答诊断中对 C2 选主类型「拆分错误」→ 保存并生成建议 → R9「拆解提示词」（低置信，默认不勾选，需手动勾选）→ 创建任务。
2. 变更行点击「打开提示词编辑器」：左参考（原问题/根因/规则定位/失败步骤/校验/快速验证结果）、中编辑（行号）、右实时 diff。
3. 修改内容 → 自动校验（占位符）→ 「快速验证（仅原问题）」→ 填版本说明 → 「保存为草稿版本」→ 变更显示 `v1.0.5 → 草稿 v1.0.6` → 「保存变更」→ 执行并验证 PASS。
4. 任务页「追加手动变更」可选择 11 种资产类型（表描述 / 实体别名 / 维度枚举值 / 聚合方式 / … / 拆解提示词 / 总结提示词）。

### E. 其它 Tab
- **回归集**：保存定位时勾选「加入回归集」或 👍 反馈自动沉淀；支持启停/删除/手工新增。
- **质量统计**：近 N 天总量 / 👍👎 / 失败 / 用户 & 管理员错误类型分布 / 修复状态。
- **设置**：GLOBAL / 按智能体 覆盖验证集配置；观察期告警 24h 内同类 👎 ≥ 2。
- 右上角铃铛：通知（审批待办、发布/回滚、观察期告警）。

## 沙箱与生产差异（验收时请知悉）
- 解析结果 / 提示词版本 / 日志为 mock 固定值，验证结论必为 PASS；生产环境由真实 System B 返回。
- 登录为模拟；生产走权限服务 `/upc/user/login`（RSA 密文）。
- 前端为 development 模式构建（沙箱 2 GB 内存无法跑 production 构建），样式/功能一致，体积更大。
- `dcar_chat_record.minio_file_path` 等列在沙箱由 `dev_minimal.sql` 补齐，生产库原生存在。
