# 问答质量管理 — 交互原型说明

> 原型文件位于 `docs/prototype/`，本文为页面与交互说明。

对应需求：
1. 管理端可针对问答结果进行**错误定位**（选表 / 指标维度提取 / 意图识别 / 拆分 / 总结）
2. 用户在问数过程中可**提交反馈**（指标 / 维度 / 意图识别 / 拆分 / 选表 / 总结 / 结果错误 + 错误描述）

## 打开方式

纯静态页面，Vue 2 + Element UI（与现有前端 `frontend/chatbi-new` 同技术栈），依赖已本地化到 `vendor/`：

```bash
cd docs/prototype
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765/index.html
```

也可直接双击 `index.html` 打开。

## 可交互点

- ①②：点 👎 → 选类型 → 提交，历史会话列表与③④会同步出现该反馈
- ③④：点行或「去定位 / 诊断」进入⑤
- ⑤：
  - 中栏每个链路环节右侧「判为 XX 错误」→ 直接填入右栏主因（再点其他类型会进入次因）
  - 点左栏 / 中栏任意步骤 → 右栏「出错步骤」联动选中
  - 主因选「选表错误」出现「实际表 → 应选表」；选「指标/维度」出现细分 + 「实际 → 应为」
  - 「修复方式」选中后出现对应管理页面快捷跳转
  - 保存后回到④，反馈状态自动流转为「已定位」

### 调优闭环（⑤→⑨→⑩）
- ⑤ 诊断页「保存并生成调优建议」→ 规则引擎按主因生成建议（选表→表描述+知识库+召回配置；指标维度→别名/枚举值；拆分→agg_type/提示词；总结→提示词）→ 进入 ⑨
- ⑨ 勾选/编辑建议 → 「执行并验证」→ 拍快照 → 状态 验证中（进度条模拟）→ 待发布
- 「提交审批」：有退化时必须填确认说明 → 状态 待审批 → ⑪ 超级管理员通过后系统自动发布（驳回回到待发布）；发布后显示线上复验与观察期（24h 内同类 👎 ≥ 2 条红色告警）
- 提示词类变更点「编辑器」→ 三栏编辑器，保存生成新版本（不激活）
- 「回退」：VERIFIED / PUBLISHED 均可，恢复快照，需填原因；回退后可「复制为新任务」
- 「修改建议重新验证」→ round+1 回到草稿

设计文档见 `./03-自动调优设计.md`。
