## 功能全景

```
用户问数 ──👎 反馈──▶ 反馈列表 ──▶ 问答诊断（链路追踪 · 错误定位）
                                        │
                                        ▼ 保存并生成调优建议
                              调优任务（建议 diff · 提示词编辑器）
                                        │ 执行并验证（草稿态 · 快照）
                                        ▼
                                   验证报告（逐题前后对比 · 退化检测）
                                        │ 提交审批
                                        ▼
                              超级管理员审批 ──通过──▶ 发布 ──▶ 观察期告警 ──▶ 回退（恢复快照）
                                        └──驳回──▶ 修改建议重跑
```
