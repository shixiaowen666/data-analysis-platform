🧠 目标与输入

      

        
        条目：
        
        
          片大小（指标/维度/表/知识，条每片，运行时生效）
          
          
          
          
        
        
      

      

        说明：四类生成统一采用「输入全量、输出分片」：每片提示词都注入全部表/维度/指标清单作为上下文（保证同名跨表描述一致），仅 {output_scope} 随片变化。确认效果后到本页「生成与采纳」tab 正式生成（候选池展示 → 点采纳才写 database_meta.json），片大小由后端固定（指标50/维度60/表30/知识60，随 LLM_MAX_TOKENS 调整）。

        本页仅调试提示词，不影响正式任务：片大小可临时修改（仅本页运行生效，不写回后端）；构造后 scope 按「片」生成——「单片调试」发送最终提示词文本框当前内容（默认当前片，可手改），旁边下拉可切换其他片（切换会重新合成文本框）；「全部调试」按当前片大小逐片跑完并核对覆盖率（使用当前模板与变量框内容）；选「全部（四类依次）」时四类按 指标→维度→表→知识 顺序逐片跑完。
