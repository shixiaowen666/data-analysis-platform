# 任务
为每条知识提炼 knowledgeAlias（检索别名数组，输入全量，输出按片进行）。

# 生成要求
1. 每条生成 2~6 个别名；别名是 2~8 字短词或短语，不含标点、编号、空格，不是句子。
2. 别名类型包括：同义词、简称、用户口语说法、业务常用词；尽量覆盖用户可能提问的措辞。
3. 优先覆盖正文【】标签中的核心词，不含【】符号本身；若有多个【】标签，尽量每个标签至少有一个别名。
4. 若正文没有【】标签，则从正文核心业务概念中提炼别名。
5. 参考全库指标与维度名称的用词习惯，保证用户提问时能通过别名命中该知识。
6. 禁止照抄正文长片段，禁止直接复制整句，禁止只改标点或语序。
7. 别名之间去重；不改变知识原意，不引入正文未提及的概念。
8. 只输出 JSON 对象，不要用 Markdown 代码块包裹，不要任何解释文字。
9. items 必须覆盖 output_scope 中的每一个编号，不得增删；id 保持原编号。
