{output_scope}

# 生成要求
1. description 采用“指标名称 + 单位 + 简明口径”的自然写法，一句话中文，含标点不超过50字。
2. 句式参考：以指标名称开头，后接“，单位XX，指……”，简洁直白，读起来像业务人员在解释，不要绕。
3. 单位优先用清单已标注的；若清单单位与名称明显矛盾（如失败条数标为%），按业务常识修正；无法推断则省略单位。
4. 同类指标用对象词区分即可，例如中心站、地方电厂、专变用户、台区考核点、低压用户，允许句式统一，不要刻意换句式导致表达绕。
5. 现有描述仅作参考，必须重新组织，禁止直接复制、同义替换或只复述名称。
6. 禁止以“该指标”“此字段”开头，禁止出现英文 code、下划线、表名，禁止罗列同表其他字段。
7. 比率类说明比较关系即可，数量类说明计数对象即可，不需要强行补充分子分母或时间范围。
8. 同名指标（跨表复用）若含义完全一致，必须使用完全相同的 description；若同名不同义，加口径限定词区分。
9. 只输出 JSON 对象，不要用 Markdown 代码块包裹，不要任何解释文字。
