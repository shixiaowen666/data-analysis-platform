## 二、确认存在的漏洞

以下漏洞所在依赖版本处于受影响范围。

### 1. Spring Web UriComponentsBuilder URL解析不当（CVE-2024-22243）

| 项目 | 详情 |
|------|------|
| **影响范围** | Spring Framework 5.3.0 - 5.3.31 |
| **修复版本** | 5.3.32 |
| **当前版本** | 5.3.31（Spring Boot 2.7.18 内置） |
| **风险说明** | 攻击者通过构造特殊 URL 可触发 SSRF（服务端请求伪造） |
| **建议** | 升级 Spring Framework 至 5.3.32+，或在 pom.xml 中覆盖 `spring-framework.version` |

### 2. Spring Web UriComponentsBuilder URL解析不当（CVE-2024-22259）

| 项目 | 详情 |
|------|------|
| **影响范围** | Spring Framework 5.3.0 - 5.3.31 |
| **修复版本** | 5.3.32 |
| **当前版本** | 5.3.31 |
| **风险说明** | URL 解析逻辑缺陷，可能导致开放重定向或 Host 头注入 |
| **建议** | 同 CVE-2024-22243，升级至 5.3.32+ |

### 3. Spring Framework ETags 解析拒绝服务（CVE-2024-38809）

| 项目 | 详情 |
|------|------|
| **影响范围** | Spring Framework 5.3.0 - 5.3.39 |
| **修复版本** | 5.3.40 |
| **当前版本** | 5.3.31 |
| **风险说明** | 恶意 ETag 头可导致 DoS |
| **建议** | 升级 Spring Framework 至 5.3.40+ |

### 4. Spring Framework 目录遍历（CVE-2024-38816）

| 项目 | 详情 |
|------|------|
| **影响范围** | Spring Framework 5.3.0 - 5.3.38 |
| **修复版本** | 5.3.39 |
| **当前版本** | 5.3.31 |
| **风险说明** | 使用 `RouterFunction` + `FileSystemResource` 时存在目录遍历。本项目未使用该组合，实际利用可能性低 |
| **建议** | 升级 Spring Framework 至 5.3.39+ |

### 5. Spring Framework 目录遍历（CVE-2024-38819）

| 项目 | 详情 |
|------|------|
| **影响范围** | Spring Framework 5.3.0 - 5.3.38 |
| **修复版本** | 5.3.39 |
| **当前版本** | 5.3.31 |
| **风险说明** | 通过 `WebMvc.fn` 或 `WebFlux.fn` 提供静态资源时存在目录遍历 |
| **建议** | 同 CVE-2024-38816 |

## 三、部署配置风险

### Redis 未授权访问

**状态**：存在风险

`application.yml` 中 Redis 未设置密码：

```yaml
redis:
    host: ip
    port: port
    password:          # 空
```

**建议**：设置强密码、防火墙限制内网访问、禁用危险命令（`CONFIG`、`FLUSHALL`）。

## 四、总结

| 类别 | 数量 |
|------|------|
| 确认不存在 | 35 项 |
| 确认存在（依赖版本） | 5 项（均为 Spring Framework 5.3.31 未升级导致） |
| 部署配置风险 | 1 项（Redis 未授权访问） |

**核心问题**：Spring Boot 2.7.18 已 EOL（生命周期终止），内置 Spring Framework 5.3.31 落后于最新安全补丁版本（5.3.40+）。5 个 Spring Framework CVE 可通过在 pom.xml 中覆盖 `spring-framework.version` 至 5.3.40+ 一次性修复。
