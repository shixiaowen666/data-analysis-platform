# 智能问数查询

```
POST http://ip/api/v1/chat-server/chat
```

### 请求

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `aicode` | String | 是 | 智能体编码 |
| `question` | String | 是 | 用户问题 |
| `chatSessionId` | String | 否 | 会话ID。不传则新建会话，传了则在已有会话中追加对话 |

### 返回 `CommonVo`

```json
{
  "ret": "success",
  "code": 200,
  "message": null,
  "data": {
    "chatSessionId": "uuid",
    "chatId": "uuid",
    "host": "192.168.x.x",
    "timestamp": 1719000000000
  }
}
```

### 说明

- `chatSessionId`：会话唯一标识
- `chatId`：本次对话的唯一标识，用于后续 WebSocket 订阅指定 Pod 的 Stream `llm_progress_{host}`
- `host`：当前处理 Pod 的 IP/主机名，前端通过它确定 WebSocket 连接的 Pod 节点

### 错误返回

```json
{
  "ret": "fail",
  "code": 400,
  "message": "智能体编码(aicode)不能为空",
  "data": null
}
```
