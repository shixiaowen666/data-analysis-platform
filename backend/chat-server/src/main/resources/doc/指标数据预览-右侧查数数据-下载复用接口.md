

# GETDATA 查询接口

## 基本信息

- **路径**: `ip:9099/api/chat-server/getdata`
- **方法**: `POST`

## 请求头

| Header | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | String | 是 | JWT Token，格式 `Bearer <token>` |
| tenantid | String | 是 | 租户ID |
| Content-Type | String | 是 | `application/json` |

---

## 入参

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| dimList | Array\<Dim\> | 否 | 维度列表 |
| indexList | Array\<Index\> | 否 | 指标列表 |
| dateGranularity | String | 否 | 日期粒度 `day`/`week`/`month`/`quarter`/`year`，默认 `day` |
| timeRange | Object | 否 | 时间范围，见下方 |
| filters | Array\<Filter\> | 否 | 过滤条件 |
| orderList | Array\<Order\> | 否 | 普通排序 |
| top | Object | 否 | TOP N / 分组TOP，含排序 |
| downloadFlag | Integer | 否 | `0`=查询（返回JSON） `1`=下载（返回Excel文件流） |
| chartType | Integer | 否 | 图表类型，默认 `1` |
| pageNo | Integer | 否 | 页码，默认 `1` |
| pageSize | Integer | 否 | 每页条数，默认 `20` |

### Dim

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | `olap_basic_pro.id` |
| dimKey | String | 否 | 维度英文名 |
| dimName | String | 否 | 维度中文名 |

### Index

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | `olap_basic_pro.id` |
| indKey | String | 否 | 指标英文名 |
| indName | String | 否 | 指标中文名 |
| fieldStyle | Integer | 否 | 格式化类型 |
| decimalPoint | Integer | 否 | 小数位数 |

### TimeRange

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start | String | 是 | 开始日期，格式 `yyyy-MM-dd` |
| end | String | 是 | 结束日期，格式 `yyyy-MM-dd` |

### Filter

| 字段 | 类型 | 必填 | 说明                              |
|------|------|------|---------------------------------|
| filterField | Object | 是 | 过滤字段信息，见下方                      |
| operator | Integer | 是 | 比较类型，见 [operator 枚举](#operator-枚举) |
| filterValue | String | 是 | 比较值                             |
| logicType | Integer | 否 | 逻辑运算符，`0`=AND `1`=OR            |

**filterField**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fieldClazz | Integer | 是 | `0`=维度 `1`=指标 |
| id | Long | 否 | `olap_basic_pro.id` |
| key | String | 是 | 字段英文名 |
| name | String | 否 | 字段中文名 |

### Order

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 排序字段 `olap_basic_pro.id` |
| key | String | 否 | 字段英文名 |
| name | String | 否 | 字段中文名 |
| order | String | 是 | `desc` 降序 / `asc` 升序 |

### Top

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| groupDims | Array\<GroupDim\> | 否 | 分组维度列表，非空时启用分组TOP |
| orders | Array\<Order\> | 否 | TOP 排序规则 |
| topNum | Integer | 否 | TOP N 的 N 值 |

**GroupDim**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 分组维度 `olap_basic_pro.id` |
| dimKey | String | 否 | 维度英文名 |
| dimName | String | 否 | 维度中文名 |

---

## 返回

> `downloadFlag=0`（查询）：返回 JSON；`downloadFlag=1`（下载）：返回 Excel 文件，`Content-Disposition: attachment; filename=data.xlsx`

### 查询（downloadFlag=0）

### 成功

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | `200` |
| message | String | `success` |
| data | Object | 见下方 |

### Data

| 字段 | 类型 | 说明 |
|------|------|------|
| total | Long | 总记录数 |
| columns | Array\<ColumnMeta\> | 列元数据 |
| records | Array\<Map\> | 数据行，key=字段标识 value=已格式化值 |
| sql | String | 执行的 SQL 信息（JSON 字符串） |
| page | Integer | 当前页码 |
| pageSize | Integer | 每页条数 |

### ColumnMeta

| 字段 | 类型 | 说明 |
|------|------|------|
| key | String | 字段标识 |
| name | String | 中文名 |
| type | String | `dimension` / `indicator` |
| unit | String | 单位 |
| precision | Integer | 小数位数 |

### 失败

| 字段 | 类型 | 说明 |
|------|------|------|
| ret | String | `fail` |
| code | Integer | 错误码，见下方 |
| message | String | 错误描述 |

---

## 枚举

### operator（比较类型）

| 值 | 说明 |
|---|------|
| 0 | > |
| 1 | < |
| 2 | = |
| 3 | >= |
| 4 | <= |
| 5 | in |
| 6 | not in |
| 7 | != |
| 8 | like |
| 9 | not like |

### ChartType

| 值 | 说明 |
|---|------|
| 1 | 表格 |
| 2 | 柱状图 |
| 3 | 折线图 |
| 4 | 饼图 |
| 5 | 指标卡 |
| 6 | 交叉表 |

### 错误码

| code | 说明 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 示例

### 请求

```json
{
  "dimList": [
    {"id": 90, "dimKey": "ptdate", "dimName": "日期"},
    {"id": 2383, "dimKey": "institution", "dimName": "分行机构"}
  ],
  "indexList": [
    {"id": 145, "indKey": "deposit_balance", "indName": "存款余额"}
  ],
  "dateGranularity": "day",
  "timeRange": {"start": "2026-03-02", "end": "2026-07-29"},
  "filters": [
    {
      "filterField": {"fieldClazz": 0, "key": "institution", "name": "分行机构"},
      "operator": 2,
      "filterValue": "北京分行"
    }
  ],
  "orderList": [
    {"id": 145, "key": "deposit_balance", "name": "存款余额", "order": "desc"}
  ],
  "top": {
    "groupDims": [{"id": 90}],
    "orders": [{"id": 145, "key": "deposit_balance", "name": "存款余额", "order": "desc"}],
    "topNum": 10
  },
  "downloadFlag": 0,
  "chartType": 1,
  "pageNo": 1,
  "pageSize": 20
}
```

```json
    ],

      {"institution": "北京分行", "deposit_balance": "116,010,000.00"},
      {"institution": "上海分行", "deposit_balance": "16,060,000.00"}
    ],
    "sql": "{...}",
    "page": 1,
    "pageSize": 20
  }
}
```

```json
{

  "code": 401,
  "message": "token无效，非法登陆"

```
