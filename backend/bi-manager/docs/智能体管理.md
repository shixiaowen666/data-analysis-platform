# 智能体管理接口文档

Base URL: `/v1/aibody`

---

## 接口列表

| 序号 | 方法 | 路径 | 说明 |
|:---:|------|------|------|
| 1 | GET | `/v1/aibody/list` | 智能体分页列表 |
| 2 | GET | `/v1/aibody/info/{code}` | 智能体详情 |
| 3 | POST | `/v1/aibody/save` | 创建/编辑智能体 |
| 4 | GET | `/v1/aibody/del/{code}` | 删除智能体 |
| 5 | GET | `/v1/aibody/candidate-tables` | 获取数据源下可选的事实表/分析模型 |

**依赖接口**（其他模块）：

| 序号 | 方法 | 路径 | 说明 |
|:---:|------|------|------|
| 6 | GET | `/v1/field-mappings/data-sources` | 获取数据源选项列表 |

---

## 1. 智能体列表

### 请求

```
GET /v1/aibody/list
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| keyword | String | 否 | 按名称模糊搜索 |
| page | Integer | 是 | 页码，≥1 |
| pageSize | Integer | 是 | 每页条数，≥1 |

### 响应

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "code": "uuid-string",
        "name": "智能体名称",
        "interactionMode": 0,
        "authorizeStrategy": 0,
        "themeCode": null,
        "tenantId": 1,
        "createdAt": "2026-06-29T10:00:00",
        "updatedAt": "2026-06-29T10:00:00"
      }
    ],
    "total": 1,
    "page": 1,
    "pageSize": 20
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| list[].id | Integer | 智能体ID |
| list[].code | String | 智能体编码 |
| list[].name | String | 名称 |
| list[].interactionMode | Integer | 0-多维分析 1-即席分析 |
| list[].authorizeStrategy | Integer | 0-私有 1-公开 2-自定义 |
| list[].themeCode | String | 主题编码 |
| list[].tenantId | Long | 租户ID |
| list[].createdAt | DateTime | 创建时间 |
| list[].updatedAt | DateTime | 更新时间 |

```json
    "createdBy": 0,

    "updatedAt": "2026-06-29T10:00:00",
    "tableRelations": [
      {
        "id": 1,
        "relationId": 16,
        "sourceId": 1,
        "tableName": "dws_income_index_month",
        "tableComment": "收入指标月表",

    "knowledgeList": [
      {
        "id": 1,

  }

```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 智能体ID |
| code | String | 智能体编码 |

| interactionMode | Integer | 0-多维分析 1-即席分析（废弃） |

| createdBy | Long | 创建人 |
| createdAt | DateTime | 创建时间 |
| updatedBy | Long | 修改人 |
| updatedAt | DateTime | 修改时间 |

### tableRelations 关联数据表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 关联记录ID |
| relationId | Long | 关联对象ID |
| sourceId | Long | 数据源ID |
| tableName | String | 表名/模型名 |
| tableComment | String | 表注释 |
| relationType | Integer | 0-关联事实表 1-关联分析模型 |

### knowledgeList 知识库

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 记录ID |
| aiBodyId | Long | 所属智能体ID |
| knowledgeElement | String | 知识内容 |
| knowledgeAlias | String | 别名（JSON字符串） |
| createdAt | DateTime | 创建时间 |

## 3. 创建/编辑智能体

### 请求

```
POST /v1/aibody/save
Content-Type: application/json
```

```json
{
  "name": "智能体名称",
  "code": "uuid-string（编辑时传入，新建时为空）",
  "description": "描述信息",
  "tableRelations": [
    {
      "relationId": 16,
      "sourceId": 1,
      "tableName": "dws_income_index_month",
      "tableComment": "收入指标月表",
      "relationType": 0
    }
  ],
  "knowledgeList": [
    {
      "knowledgeElement": "收入 = 门诊收入 + 住院收入",
      "knowledgeAlias": "收入口径"
    }
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| name | String | 是 | 智能体名称 |
| code | String | 否 | 智能体编码，新建时为空，编辑时传入 |
| description | String | 否 | 描述 |

### tableRelations 子对象

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| relationId | Long | 是 | 关联对象ID（事实表ID或数据模型ID） |
| sourceId | Long | 是 | 数据源ID |
| tableName | String | 是 | 表名 |
| tableComment | String | 否 | 表注释 |
| relationType | Integer | 否 | 0-关联事实表 1-关联分析模型，默认 0 |

### knowledgeList 子对象

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| knowledgeElement | String | 是 | 知识内容 |
| knowledgeAlias | String | 否 | 别名（JSON字符串） |

### 响应

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

> **逻辑**：`code` 为空 → 新建；`code` 非空 → 编辑（先删旧关联再重新写入）。

## 5. 候选数据表

### 请求

```
GET /v1/aibody/candidate-tables
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| sourceId | Long | 是 | 数据源ID |
| keyword | String | 否 | 按表名/中文名模糊搜索 |

### 响应

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "relationId": 3,
      "sourceId": 1,
      "tableName": "dim_user",
      "tableComment": "用户维度表",
      "relationType": 0
    },
    {
      "id": null,
      "relationId": 2,
      "sourceId": 1,
      "tableName": "收入模型",
      "tableComment": "收入相关分析模型",
      "relationType": 1
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 关联记录ID（模型时为null） |
| relationId | Long | 关联对象ID |
| sourceId | Long | 数据源ID |
| tableName | String | 表名/模型名 |
| tableComment | String | 表注释 |
| relationType | Integer | 0-物理表 1-分析模型 |

### 逻辑

分两支查询后合并：

1. **分析模型** — 查 `olap_data_model`（status=1），`relationType = 1`
2. **物理表** — 查 `olap_table_pro`，排除已在模型中的事实表，`relationType = 0`

> 数据模型排在前面，物理表在后面。

## 6. 数据源选项

### 请求

```
GET /v1/field-mappings/data-sources
```

无请求参数。

### 响应

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "name": "数据源名称",
      "dbName": "default_db",
      "dbType": "MySQL"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 数据源ID |
| name | String | 数据源名称 |
| dbName | String | 默认库名 |
| dbType | String | 数据库类型 |
