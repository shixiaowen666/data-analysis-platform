# 维度值查询接口

## 接口

**GET** `/v1/dimensions/{id}/values`

获取指定维度的全量维度值列表，不分页。

---

## 请求参数（Path）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | Long | 是 | 维度 ID |

---

## 响应结构

`data` 为字符串数组，元素为维度值。

---

## 请求示例

```shell
curl -X GET http://localhost:8080/v1/dimensions/1001/values
```

---

## 响应示例

```json
{
  "code": 200,
  "data": ["北京", "上海", "广州", "深圳", "杭州"]
}
```
