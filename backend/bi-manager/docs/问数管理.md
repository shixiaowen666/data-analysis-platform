# 问数管理 API 文档

Base URL: `/api/v1/chat`

---

## 1. 接口概览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/chat/agent/sessions` | 获取智能体的会话列表 |
| GET | `/api/v1/chat/session/del/{sessionId}` | 删除会话 |
| POST | `/api/v1/chat/feedback` | 对话反馈 |
| GET | `/api/v1/chat/session/list` | 历史会话记录列表 |
| GET | `/api/v1/chat/session/info` | 会话历史记录详情 |
| GET | `/api/v1/chat/info` | 问话执行结果 |

---

## 2. 通用响应格式

所有接口返回统一结构 `R<T>`：

```json
{
  "code": 200,
  "message": "success",
  "data": "<T>"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 200 成功，其他为错误码 |
| message | String | 提示信息 |
| data | T | 业务数据 |

---

## 3. 接口详情

### 3.1 获取智能体的会话列表

```
GET /api/v1/chat/agent/sessions?aiBodyCode={aiBodyCode}
```

**Query 参数:**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| aiBodyCode | String | 是 | 智能体编码 |

**响应 data (List[ChatSessionVO]):**

```json
[
  {
    "id": 1,
    "chatSessionId": "a1b2c3d4e5f6",
    "aiBodyCode": "AGT001",
    "aiBodyName": "销售分析智能体",
    "chatName": "本月销售趋势分析",
    "interactionMode": 0,
    "isCalculate": 1,
    "enableContext": true,
    "createdAt": "2026-06-20T10:00:00",
    "updatedAt": "2026-06-24T15:30:00"
  }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 记录 ID |
| chatSessionId | String | 会话 ID |
| aiBodyCode | String | 智能体编码 |
| aiBodyName | String | 智能体名称 |
| chatName | String | 会话名称 |
| interactionMode | Integer | 交互模式：0-多维分析，1-即席分析 |
| isCalculate | Integer | 是否汇总计算：0-否，1-是 |
| enableContext | Boolean | 是否开启上下文引用 |
| createdAt | String | 创建时间 |
| updatedAt | String | 更新时间（排序字段，desc） |

**正例:**

```bash
curl "http://localhost:8080/api/v1/chat/agent/sessions?aiBodyCode=AGT001"
```

**反例:**

```bash
# 缺少必填参数
curl "http://localhost:8080/api/v1/chat/agent/sessions"
```

```json
{
  "code": 400,
  "message": "Required String parameter 'aiBodyCode' is not present",
  "data": null
}
```

### 3.2 删除会话

```
GET /api/v1/chat/session/del/{sessionId}
```

**Path 参数:**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| sessionId | String | 是 | 会话 ID |

**说明:** 删除会话时，该会话下的所有问答记录也会一并删除。

**响应:** `R<Void>` 无 data。

**正例:**

```bash
curl "http://localhost:8080/api/v1/chat/session/del/a1b2c3d4e5f6"
```

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

---

### 3.3 对话反馈

```
POST /api/v1/chat/feedback
Content-Type: application/json
```

**Request Body (ChatFeedbackDTO):**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 问答记录 ID |
| feedback | Integer | 是 | 反馈：1-赞，-1-踩 |
| reason | String | 否 | 点踩原因 |

**响应:** `R<Void>` 无 data。

**正例:**

```bash
curl -X POST "http://localhost:8080/api/v1/chat/feedback" \
  -H "Content-Type: application/json" \
  -d '{
    "id": 1001,
    "feedback": 1
  }'
```

```bash
curl -X POST "http://localhost:8080/api/v1/chat/feedback" \
  -H "Content-Type: application/json" \
  -d '{
    "id": 1002,
    "feedback": -1,
    "reason": "数据不准确"
  }'
```

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

**反例:**

```bash
# 缺少必填字段
curl -X POST "http://localhost:8080/api/v1/chat/feedback" \
  -H "Content-Type: application/json" \
  -d '{}'
```

```json
{
  "code": 400,
  "message": "问答记录ID不能为空",
  "data": null
}
```

```bash
# 记录不存在
curl -X POST "http://localhost:8080/api/v1/chat/feedback" \
  -H "Content-Type: application/json" \
  -d '{"id": 99999, "feedback": 1}'
```

```json
{
  "code": 404,
  "message": "问答记录不存在",
  "data": null
}
```

### 3.4 历史会话记录列表

```
GET /api/v1/chat/session/list
```

**说明:** 按更新时间分组返回历史会话，分组维度为：今天、昨天、近7天、近30天、近半年、半年以上。

**响应 data (Map[String, List[ChatRecord]]):**

```json
{
  "today": [
    {
      "id": 10,
      "chatSessionId": "aaa111",
      "aiBodyCode": "AGT001",
      "chatName": "今日销售分析",
      "interactionMode": 0,
      "isCalculate": 1,
      "enableContext": true,
      "status": 1,
      "createdAt": "2026-06-24T09:00:00",
      "updatedAt": "2026-06-24T14:00:00"
    }
  ],
  "yesterday": [],
  "lastWeek": [
    {
      "id": 5,
      "chatSessionId": "bbb222",
      "aiBodyCode": "AGT001",
      "chatName": "库存周转分析",
      "interactionMode": 1,
      "isCalculate": 0,
      "enableContext": false,
      "status": 1,
      "createdAt": "2026-06-20T10:00:00",
      "updatedAt": "2026-06-22T16:30:00"
    }
  ],
  "lastMonth": [],
  "lastSixMonth": [],
  "moreThanSixMonth": []
}
```

| 分组 key | 说明 |
|------|------|
| today | 今天 |
| yesterday | 昨天 |
| lastWeek | 近 7 天 |
| lastMonth | 近 30 天 |
| lastSixMonth | 近 180 天 |
| moreThanSixMonth | 半年以上 |

**ChatRecord 字段说明:**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 记录 ID |
| chatSessionId | String | 会话 ID |
| aiBodyCode | String | 智能体编码 |
| chatName | String | 会话名称 |
| interactionMode | Integer | 交互模式：0-多维分析，1-即席分析 |
| isCalculate | Integer | 是否汇总计算 |
| enableContext | Boolean | 是否开启上下文 |
| status | Integer | 状态：0-未生效，1-已生效 |
| createdAt | String | 创建时间 |
| updatedAt | String | 更新时间 |

**正例:**

```bash
curl "http://localhost:8080/api/v1/chat/session/list"
```

**反例:**

```bash
# 无任何会话时仍返回各个分组的空数组
curl "http://localhost:8080/api/v1/chat/session/list"
```

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "today": [],
    "yesterday": [],
    "lastWeek": [],
    "lastMonth": [],
    "lastSixMonth": [],
    "moreThanSixMonth": []
  }
}
```

### 3.5 会话历史记录详情

```
GET /api/v1/chat/session/info?chatSessionId={chatSessionId}
```

**Query 参数:**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| chatSessionId | String | 是 | 会话 ID |

**响应 data (ChatRecordDTO):**

```json
{
  "id": 1,
  "chatSessionId": "aaa111",
  "chatName": "今日销售分析",
  "aiBodyCode": "AGT001",
  "name": "销售分析智能体",
  "chatInfo": [
    {
      "chatId": "chat001",
      "chatItemInfo": [
        {
          "type": "user",
          "question": "本月销售额是多少？",
          "itemId": 1,
          "chartData": null,
          "updateUser": "张三",
          "updateTime": "2026-06-24 10:00:00",
          "think": null,
          "status": 1,
          "interactionMode": 0,
          "enableContext": true,
          "host": "ip",
          "questionRewriter": null,
          "stepType": ""
        },
        {
          "type": "ai",
          "question": null,
          "itemId": 2,
          "chartData": { "...": "图表数据" },
          "updateUser": null,
          "updateTime": null,
          "think": {
            "status": 1,
            "message": "思考完成",
            "speed": 1200
          },
          "status": 1,
          "interactionMode": 0,
          "enableContext": true,
          "host": null,
          "questionRewriter": null,
          "stepType": "query"
        }
      ]
    }
  ]
}
```

**ChatRecordDTO 字段说明:**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 记录 ID |
| chatSessionId | String | 会话 ID |
| chatName | String | 会话名称 |
| aiBodyCode | String | 智能体编码 |
| name | String | 智能体名称 |
| chatInfo | List[ChatDTO] | 该会话下所有对话列表 |

**ChatDTO 字段说明:**

| 字段 | 类型 | 说明 |
|------|------|------|
| chatId | String | 对话 ID（一次一问一答） |
| chatItemInfo | List[ChatItemInfo] | 对话中的每个条目（问题、回答、计算步骤等） |

**ChatItemInfo 字段说明:**

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 类型：`user`-用户，`ai`-模型 |
| question | String | 问题内容 |
| itemId | Integer | 子项 ID |
| chartData | Object | 图表/数据结果 |
| updateUser | String | 修改人 |
| updateTime | String | 修改时间 |
| think | ThinkDTO | 思考过程 |
| status | Integer | 状态：0-正在思考，1-已完成，2-正在查数 |
| interactionMode | Integer | 交互模式 |
| enableContext | Boolean | 是否开启上下文引用 |
| host | String | host 地址 |
| questionRewriter | String | 问题重写 |
| stepType | String | 步骤类型：`query`、`compute`、`summarize` |

**ThinkDTO 字段说明:**

| 字段 | 类型 | 说明 |
|------|------|------|
| status | Integer | 状态：0-异常中断，1-结束，2-输出中 |
| message | String | 输出内容 |
| speed | Long | 耗时（ms） |

**正例:**

```bash
curl "http://localhost:8080/api/v1/chat/session/info?chatSessionId=aaa111"
```

**反例:**

```bash
# 会话不存在
curl "http://localhost:8080/api/v1/chat/session/info?chatSessionId=NOTEXIST"
```

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

### 3.6 问话执行结果

```
GET /api/v1/chat/info?chatSessionId={chatSessionId}&chatId={chatId}
```

**Query 参数:**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| chatSessionId | String | 是 | 会话 ID |
| chatId | String | 是 | 对话 ID |

**说明:** 获取某次对话（一问一答）的完整执行结果。与 `session/info` 返回整个会话下多组对话不同，此接口只返回指定 `chatId` 的单组对话。

**响应 data (ChatDTO):**

```json
{
  "chatId": "chat001",
  "chatItemInfo": [
    {
      "type": "user",
      "question": "本月销售额是多少？",
      "itemId": 1,
      "chartData": null,
      "updateUser": "张三",
      "updateTime": "2026-06-24 10:00:00",
      "think": null,
      "status": 1,
      "interactionMode": 0,
      "enableContext": true,
      "host": "ip",
      "questionRewriter": null,
      "stepType": ""
    },
    {
      "type": "ai",
      "question": null,
      "itemId": 2,
      "chartData": { "total": 1250000 },
      "updateUser": null,
      "updateTime": null,
      "think": {
        "status": 1,
        "message": "SELECT SUM(amount) FROM fact_sales WHERE month=6",
        "speed": 800
      },
      "status": 1,
      "interactionMode": 0,
      "enableContext": true,
      "host": null,
      "questionRewriter": null,
      "stepType": "query"
    }
  ]
}
```

**字段说明:** 同 3.5 中 ChatDTO / ChatItemInfo / ThinkDTO。

**正例:**

```bash
curl "http://localhost:8080/api/v1/chat/info?chatSessionId=aaa111&chatId=chat001"
```

**反例:**

```bash
# 对话记录不存在
curl "http://localhost:8080/api/v1/chat/info?chatSessionId=aaa111&chatId=NOTEXIST"
```

```json
{
  "code": 404,
  "message": "对话记录不存在",
  "data": null
}
```

## 4. 枚举值速查

| 字段 | 值 | 含义 |
|------|------|------|
| interactionMode | 0 | 多维分析 |
| interactionMode | 1 | 即席分析 |
| isCalculate | 0 | 不汇总计算 |
| isCalculate | 1 | 汇总计算 |
| status (ChatRecord) | 0 | 未生效 |
| status (ChatRecord) | 1 | 已生效 |
| status (ChatItemInfo) | 0 | 正在思考 |
| status (ChatItemInfo) | 1 | 已完成 |
| status (ChatItemInfo) | 2 | 正在查数 |
| status (ThinkDTO) | 0 | 异常中断 |
| status (ThinkDTO) | 1 | 结束 |
| status (ThinkDTO) | 2 | 输出中 |
| type | user | 用户消息 |
| type | ai | 模型回复 |
| feedback | 1 | 赞 |
| feedback | -1 | 踩 |
| feedback | 0 | 默认（无反馈） |
| stepType | query | 查询 |
| stepType | compute | 计算 |
| stepType | summarize | 总结 |
