| # | 漏洞名称 | 严重程度 | 说明 |

| 1 | Spring Framework ETags 解析 DoS（CVE-2024-38809） | 中 | 当前 5.3.31，修复版本 5.3.40 |
| 2 | Spring Framework 目录遍历（CVE-2024-38816） | 中 | 当前 5.3.31，修复版本 5.3.41 |
| 3 | Spring Framework 目录遍历（CVE-2024-38819） | 中 | 当前 5.3.31，修复版本 5.3.41 |

| 5 | Spring Web UriComponentsBuilder URL 解析不当（CVE-2024-22259） | 高 | 当前 5.3.31，修复版本 5.3.39 |

**修复方案**：Spring Boot 2.7.x 已 EOL，无法通过升级 SB 版本修复。需在 pom.xml 中显式覆盖 Spring Framework 版本：

```xml
<properties>
    <spring-framework.version>5.3.41</spring-framework.version>
</properties>
```
