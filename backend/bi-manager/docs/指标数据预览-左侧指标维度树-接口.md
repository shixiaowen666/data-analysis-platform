# 数据预览-左侧指标维度树接口

## 接口

**POST** `/api/v1/report-preview/dim-metric`

> 报表设计器左侧数据源树。`type` 必须传 `"dim"` 或 `"metric"` 分别获取维度或指标列表，否则返回空列表。

---

## 请求参数（Request Body）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | String | **是** | `"dim"` 返回维度列表，`"metric"` 返回指标列表。不传或传其他值返回空列表 |
| `metricIds` | List\<Long\> | 否 | 已选中的指标 ID，用于过滤可关联的维度，并从结果中排除这些 ID |
| `dimensionIds` | List\<Long\> | 否 | 已选中的维度 ID，用于过滤可关联的指标，并从结果中排除这些 ID |
| `keyword` | String | 否 | 模糊搜索中文名称 |

**过滤逻辑：**

- 若传入 `metricIds` 或 `dimensionIds`，系统会取这些选中字段所属事实表的**交集**，只返回同样属于这些事实表的候选字段。
- 若某个选中字段没有关联任何事实表，接口会返回 `400` 错误。
- 已选中的 ID（`dimensionIds` 或 `metricIds`）不会出现在结果中。
- 若两个参数都不传，则返回全部已上线的维度/指标。

---

## 响应结构

```json
{
  "code": 0,
  "data": [ ... ]
}
```

### data 元素字段（DimMetricTreeDTO）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 字段 ID |
| `name` | String | 中文名称 |
| `key` | String | 英文名称 |

> 返回为**扁平列表**，非树形结构。前端根据 `type` 分别调用两次接口获取维度和指标。

---

## 请求示例

### 获取维度列表

```shell
curl -X POST /api/v1/report-preview/dim-metric \
  -H "Content-Type: application/json" \
  -d '{
    "type": "dim",
    "metricIds": [],
    "dimensionIds": [],
    "keyword": "城市"
  }'
```

### 获取指标列表（根据已选维度过滤）

```shell
curl -X POST /api/v1/report-preview/dim-metric \
  -H "Content-Type: application/json" \
  -d '{
    "type": "metric",
    "metricIds": [],
    "dimensionIds": [1001],
    "keyword": "金额"
  }'
```

### 获取维度列表（根据已选指标过滤）

```shell
curl -X POST /api/v1/report-preview/dim-metric \
  -H "Content-Type: application/json" \
  -d '{
    "type": "dim",
    "metricIds": [2001, 2002],
    "dimensionIds": [],
    "keyword": "时间"
  }'
```

### 获取维度列表（同时传入已选指标和已选维度过滤）

```shell
curl -X POST /api/v1/report-preview/dim-metric \
  -H "Content-Type: application/json" \
  -d '{
    "type": "dim",
    "metricIds": [2001, 2002],
    "dimensionIds": [1001, 1002]
  }'
```

### 获取指标列表（同时传入已选指标和已选维度过滤）

```shell
curl -X POST /api/v1/report-preview/dim-metric \
  -H "Content-Type: application/json" \
  -d '{
    "type": "metric",
    "metricIds": [2001, 2002],
    "dimensionIds": [1001, 1002]
  }'
```

---

## 响应示例

### type=dim

```json
{
  "code": 0,
  "data": [
    { "id": 1001, "name": "城市", "key": "city" },
    { "id": 1002, "name": "会员等级", "key": "member_level" },
    { "id": 1003, "name": "下单日期", "key": "order_date" }
  ]
}
```

### type=metric

```json
{
  "code": 0,
  "data": [
    { "id": 2001, "name": "订单数", "key": "order_cnt" },
    { "id": 2002, "name": "交易金额", "key": "trans_amount" }
  ]
}
```
