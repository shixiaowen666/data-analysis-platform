# 删除智能体关联表

## 接口信息

| 项目 | 说明 |
|------|------|
| 请求方式 | `GET` |
| 路径 | `/v1/ai-body/relation/del` |
| 权限 | 租户隔离，仅操作当前租户数据 |

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `code` | String | 是 | 智能体编码 |
| `id` | Long | 否 | 关联表记录 ID。不传或传 `null` 时静默跳过，不执行删除 |

## 返回结果

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

## 内部逻辑

1. 校验 `id` 是否为有效值（非空且 > 0），同时校验 `code` 是否为空，任一不满足则直接返回（不抛异常）
2. 按 `id` + `code` + `tenantId` 精确匹配删除 `AiBodyRelation` 记录
3. 即使匹配不到任何记录，接口也返回成功

## 说明

- 该接口用于单独删除某个智能体的关联表，与保存时的增量插入逻辑配合使用
- 不传 `id` 时不会删除任何数据，可用于前端未确定具体记录时的安全调用
