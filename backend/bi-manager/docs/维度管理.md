# 维度接口

## 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/v1/dimensions/page` | 分页查询维度列表 |
| `POST` | `/v1/dimensions/save` | 新建/编辑维度（id 为空新建，非空编辑） |
| `GET` | `/v1/dimensions/{id}` | 获取维度详情 |

---

## 1. 分页查询维度列表

**GET** `/v1/dimensions/page`

### 请求参数（Query String）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keyword` | String | 否 | 按维度名称中文模糊匹配 |
| `dimensionType` | Integer | 否 | 维度类型：`1`-标准维，`2`-杂项维 |
| `page` | Integer | 否 | 页码，默认 `1` |
| `pageSize` | Integer | 否 | 每页条数，默认 `10` |

### 响应结构

```json
{
  "code": 0,
  "data": {
    "total": 50,
    "records": [ ... ],
    "page": 1,
    "pageSize": 10
  }
}
```

### records 元素字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 维度 ID |
| `chineseName` | String | 中文名称 |
| `englishName` | String | 英文名称 |
| `alias` | String | 别名 |
| `category` | Integer | 分类，维度固定为 `1` |
| `dimensionType` | Integer | 维度类型：`1`-标准维，`2`-杂项维 |
| `collectStatus` | Integer | 采集状态：`0`-未采集，`1`-全量采集，`2`-部分采集 |
| `status` | Integer | 状态：`0`-草稿，`1`-审批中，`2`-已上线，`3`-已下线 |

### 请求示例

```shell
# 查询所有维度
GET /v1/dimensions/page?page=1&pageSize=10

# 按关键字搜索
GET /v1/dimensions/page?keyword=城市&page=1&pageSize=10

# 按类型筛选
GET /v1/dimensions/page?dimensionType=1&page=1&pageSize=10
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "total": 2,
    "records": [
      {
        "id": 1001,
        "chineseName": "城市",
        "englishName": "city",
        "alias": null,
        "category": 1,
        "dimensionType": 1,
        "collectStatus": 1,
        "status": 2
      },
      {
        "id": 1002,
        "chineseName": "会员等级",
        "englishName": "member_level",
        "alias": null,
        "category": 1,
        "dimensionType": 2,
        "collectStatus": 0,
        "status": 0
      }
    ],
    "page": 1,
    "pageSize": 10
  }
}
```

## 2. 新建/编辑维度

**POST** `/v1/dimensions/save`

> `id` 为空新建，非空编辑。编辑时 `englishName` 不可修改。

### 请求体字段说明

请求体结构与响应详情 `DimensionDetailVO` 对称，分为**基础信息**和 **extension（扩展信息）** 两层。

#### 基础信息

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | Long | 否 | 维度 ID，新建不传，编辑必传 |
| `chineseName` | String | **是** | 中文名称 |
| `englishName` | String | **是**（新建） | 英文名称（维度编码，自动转小写），编辑时忽略 |
| `alias` | String | 否 | 别名，多个用 `｜` 分隔 |

#### extension（维度扩展信息，必填）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dimensionType` | Integer | **是** | 维度类型：`1`-标准维，`2`-杂项维 |
| `valueSourceTable` | String | 否 | 标准维-取值来源表名 |
| `valueSourceField` | String | 否 | 标准维-取值来源字段名 |
| `valueFilter` | String | 否 | 标准维-取值筛选条件（SQL WHERE 片段） |
| `valueEntries` | List\<ValueEntry\> | 否 | 杂项维-手工维值映射列表 |
| `databaseTableId` | Long | 否 | 来源库表 ID |
| `caliberDescription` | String | 否 | 口径描述 |

**ValueEntry 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `rawValue` | String | 表内值（实际存储值） |
| `displayValue` | String | 展示值（前端显示值） |

### 请求报文示例

#### 新建标准维

```json
{
  "chineseName": "城市",
  "englishName": "city",
  "alias": "城市｜city",
  "extension": {
    "dimensionType": 1,
    "valueSourceTable": "dim_city",
    "valueSourceField": "city_name",
    "valueFilter": "status = 1",
    "databaseTableId": 10,
    "caliberDescription": "用户所在城市，来源于用户注册时填写的城市信息"
  }
}
```

#### 编辑标准维

```json
{
  "id": 1001,
  "chineseName": "城市（更新）",
  "alias": "城市｜city",
  "extension": {
    "dimensionType": 1,
    "valueSourceTable": "dim_city",
    "valueSourceField": "city_name",
    "valueFilter": "status = 1",
    "databaseTableId": 10,
    "caliberDescription": "用户下单城市"
  }
}
```

#### 新建杂项维

```json
{
  "chineseName": "会员等级",
  "englishName": "member_level",
  "alias": "会员等级｜member_level",
  "extension": {
    "dimensionType": 2,
    "valueEntries": [
      { "rawValue": "0", "displayValue": "普通会员" },
      { "rawValue": "1", "displayValue": "银卡会员" },
      { "rawValue": "2", "displayValue": "金卡会员" }
    ],
    "caliberDescription": "用户会员等级，分为普通会员、银卡会员、金卡会员"
  }
}
```

## 3. 维度详情

**GET** `/v1/dimensions/{id}`

> 样例数据：`id=16` 标准维带值，`id=18` 杂项维带值。

### 响应体字段说明

#### 基本信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 维度 ID |
| `chineseName` | String | 中文名称 |
| `standardName` | String | 标准名称 |
| `alias` | String | 别名 |
| `englishName` | String | 英文名称 |
| `abbreviation` | String | 缩写 |
| `category` | Integer | 分类，维度固定为 `1` |
| `mappingList` | List | 字段映射列表 |

**mappingList 元素结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `soucreTableId` | Long | 来源表 ID |
| `soucreTableName` | String | 来源表名（db.table 格式） |
| `sourceField` | String | 来源字段 |

#### extension（维度扩展信息）

| 字段 | 类型 | 说明 |
|------|------|------|
| `dimensionType` | Integer | 维度类型：`1`-标准维，`2`-杂项维 |
| `dimensionTypeName` | String | 维度类型名称 |
| `valueSourceTable` | String | 取值来源表名（标准维） |
| `valueSourceField` | String | 取值来源字段名（标准维） |
| `valueFilter` | String | 取值筛选条件（标准维） |
| `valueEntries` | List\<ValueEntry\> | 手工维值映射（杂项维） |
| `collectStatus` | Integer | 采集状态：`0`-未采集，`1`-全量采集，`2`-部分采集 |
| `collectStatusName` | String | 采集状态名称 |
| `databaseTableId` | Long | 来源库表 ID |
| `valueFieldId` | Long | 值字段 ID |
| `valueFieldName` | String | 值字段名 |
| `caliberDescription` | String | 口径描述 |

### 响应报文示例

#### 标准维（dimensionType = 1）

```json
{
  "code": 0,
  "data": {
    "id": 1001,
    "chineseName": "城市",
    "standardName": "城市",
    "alias": "城市｜city",
    "englishName": "city",
    "abbreviation": "city",
    "category": 1,
    "mappingList": [
      {
        "soucreTableId": 10,
        "soucreTableName": "analytics.dim_city",
        "sourceField": "city_id"
      }
    ],
    "extension": {
      "dimensionType": 1,
      "dimensionTypeName": "标准维",
      "valueSourceTable": "dim_city",
      "valueSourceField": "city_name",
      "valueFilter": "status = 1",
      "valueEntries": null,
      "collectStatus": 1,
      "collectStatusName": "全量采集",
      "databaseTableId": 10,
      "valueFieldId": 101,
      "valueFieldName": "city_id",
      "caliberDescription": "用户所在城市"
    }
  }
}
```

#### 杂项维（dimensionType = 2）

  "data": {
    "id": 1002,
    "chineseName": "会员等级",

    "englishName": "member_level",

        { "rawValue": "0", "displayValue": "普通会员" },
        { "rawValue": "1", "displayValue": "银卡会员" },
        { "rawValue": "2", "displayValue": "金卡会员" }
      ],
      "collectStatus": 0,
      "collectStatusName": "未采集",
      "databaseTableId": null,

    }
