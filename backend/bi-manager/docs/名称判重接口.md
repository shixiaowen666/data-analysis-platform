# 名称判重接口

## 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/metrics/check-ename` | 指标英文名判重 |
| `POST` | `/v1/metrics/check-cname` | 指标中文名判重 |
| `POST` | `/v1/dimensions/check-ename` | 维度英文名判重 |
| `POST` | `/v1/dimensions/check-cname` | 维度中文名判重 |

---

## 1. 指标英文名判重

**POST** `/v1/metrics/check-ename`

### 请求体（JSON）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | String | 是 | 要校验的英文名称 |
| `id` | Long | 否 | 编辑场景传当前指标 ID，新建不传或传 `null` |

### 响应结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `exist` | Boolean | `true`-名称已存在，`false`-可用 |
| `errMsg` | String | 冲突时的提示信息，无冲突时为 `null` |

### 请求示例

```shell
# 新建时判重
curl -X POST http://localhost:8080/v1/metrics/check-ename \
  -H "Content-Type: application/json" \
  -d '{"name":"user_visit_cnt"}'

# 编辑时判重（排除自身）
curl -X POST http://localhost:8080/v1/metrics/check-ename \
  -H "Content-Type: application/json" \
  -d '{"name":"user_visit_cnt","id":1001}'
```

### 响应示例

```json
// 有冲突
{
  "code": 200,
  "data": {
    "exist": true,
    "errMsg": "英文名称 user_visit_cnt 已存在"
  }
}

// 无冲突
{
  "code": 200,
  "data": {
    "exist": false,
    "errMsg": null
  }
}
```
