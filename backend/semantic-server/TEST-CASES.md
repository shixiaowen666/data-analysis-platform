# 测试用例

> 执行方式：用户在页面点选维度/指标/筛选条件，按用例描述操作，核对返回结果。
> 测试环境：PostgreSQL，表 28（app_apt_mate_expense_tendency），租户 1
> 数据覆盖：2025-01-01 ~ 2026-08-13 每天都有数据

## 业务对象清单

**指标**：

| ID | 页面名称 | 类型 | 说明 |
|---|---|---|---|
| 72 | 出院人次 | 普通 | sum |
| 73 | 门急诊人次 | 普通 | sum |
| 74 | 卫生材料支出 | 快照 | 按天取值 |

| 80 | 心内系统医疗收入 | 衍生 | 医疗收入，仅系统=心内系统 |

## 1. 计算指标

### TC-CALC-001 单源无维度查询
```
操作: 只选指标「医院总人次」，不选维度
     时间范围 2026-08-02 ~ 2026-08-02
预期:
  - 返回 1 行数据
  - 返回列只有「医院总人次」1 列（不出现出院人次、门急诊人次）
  - 医院总人次的值 = 当日出院人次 + 当日门急诊人次
  - 无报错
```

### TC-CALC-002 单源有维度查询
```
操作: 选维度「科室」「系统」，选指标「医院总人次」
     时间范围 2026-08-02 ~ 2026-08-03
预期:
  - 返回列: 科室、系统、医院总人次
  - 按科室+系统分组，每组一行
  - 每组医院总人次 = 该组出院人次 + 门急诊人次
```

### TC-CALC-003 计算指标 + 显式请求子指标
```
操作: 选指标「医院总人次」「出院人次」
     时间范围 2026-08-02 ~ 2026-08-02
预期:
  - 返回列: 出院人次、医院总人次（2 列）
  - 出院人次 = 当日出院人次正常值
  - 医院总人次 = 出院人次 + 门急诊人次
  - 门急诊人次不出现
```

### TC-CALC-004 计算 + 普通混查
```
操作: 选指标「医院总人次」「医疗收入（不含药品）」
     时间范围 2026-08-02 ~ 2026-08-02
预期:
  - 返回 2 列，各自值正确，互不影响
  - 医疗收入 = 全院全部系统的收入
```

### TC-CALC-005 计算指标别名
```
操作: 选指标「医院总人次」
预期:
  - 返回列的 key 为 all_people_num（english_name），不是 calc_76_key
```

## 3. 同环比

> 页面操作：指标上开启对比开关，选对比类型

### TC-CMP-001 环比（pop）日粒度
```
操作: 选维度「日期」，选指标「出院人次」，开启对比=环比
     时间范围 2026-08-02 ~ 2026-08-02
预期:
  - 返回列: 日期、出院人次-本期、出院人次-上期、出院人次-环比
  - 上期值 = 2026-08-01 的出院人次
  - 环比 = (本期-上期)/上期 × 100，保留 1 位小数
```

### TC-CMP-002 同比（yoy）
```
操作: 选维度「日期」，选指标「出院人次」，开启对比=同比
     时间范围 2026-08-02 ~ 2026-08-02
预期:
  - 返回列: 日期、出院人次-本期、出院人次-同期、出院人次-同比
  - 同期值 = 2025-08-02 的出院人次
```

### TC-CMP-003 环比+同比（both）
```
操作: 选维度「日期」，选指标「出院人次」，开启对比=环比+同比
     时间范围 2026-08-02 ~ 2026-08-02
预期:
  - 返回 5 列: 本期、上期、环比、同期、同比
```

### TC-CMP-004 上期无数据
```
操作: 选维度「日期」，选指标「出院人次」，开启对比=环比
     时间范围 2025-01-01 ~ 2025-01-01
预期:
  - 上期值为 null（2024-12-31 无数据）
  - 环比为 null
  - 报文里字段存在，值为 null，不报错
```

### TC-CMP-005 无日期维度（整周期对比）
```
操作: 选维度「科室」，选指标「出院人次」，开启对比=环比
     时间范围 2026-08-01 ~ 2026-08-07（7天）
预期:
  - 每科室一行
  - 本期 = 8/1~8/7 合计
  - 上期 = 7/25~7/31 合计
  - 环比 = (本期-上期)/上期 × 100
```

### TC-CMP-006 月粒度环比
```
操作: 选维度「月份」，选指标「出院人次」，开启对比=环比
     时间范围 2026-06-01 ~ 2026-06-30
预期:
  - 月份列值为 2026-06
  - 上期值 = 2026 年 5 月合计
```

### TC-CMP-007 部分指标对比
```
操作: 选指标「出院人次」「医疗收入（不含药品）」
     只给出院人次开环比，医疗收入不开
     时间范围 2026-08-02 ~ 2026-08-02
预期:
  - 出院人次展开 3 列（本期/上期/环比）
  - 医疗收入只有 1 列，正常值
```

## 7. 异常场景

### TC-ERR-001 同环比缺粒度
```
操作: 接口层直接调（绕过页面），开环比但不传 dateGranularity
预期: 报错提示「同环比请求必须指定 dateGranularity」
```

### TC-ERR-002 同环比缺时间范围
```
操作: 接口层直接调，开环比但不传 timeRange
预期: 报错提示「同环比请求必须指定 timeRange」
```

### TC-ERR-003 页面选维度校验
```
操作: 页面操作确认——选衍生指标时不强制选系统维度；选快照指标时不强制选日期维度
预期: 页面不报错（后端自动处理）
```
