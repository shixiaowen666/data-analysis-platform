## 涉及漏洞详情（5 项，均源于 Spring Framework 5.3.31）

| CVE | 漏洞名称 | 修复版本 |
|---|---|---|

| CVE-2024-38816 | Spring Framework 特定条件下目录遍历漏洞 | >= 5.3.41 |
| CVE-2024-38819 | Spring Framework 特定条件下目录遍历漏洞 | >= 5.3.41 |
| CVE-2024-22243 | Spring Web UriComponentsBuilder URL解析不当漏洞 | >= 5.3.41 |
| CVE-2024-22259 | Spring Web UriComponentsBuilder URL解析不当漏洞 | >= 5.3.41 |

### 处置建议

Spring Boot 2.7.x 已于 2023 年 11 月结束 OSS 支持，Spring Framework 5.3.31 是 2.7.18 绑定的最终版本。修复这 5 个 CVE 需要 Spring Framework >= 5.3.41，可通过以下方式：

1. **推荐**：迁移到 Spring Boot 3.x，Spring Framework 6.x 有持续的安全更新
2. **备选**：购买 VMware Tanzu Spring 商业支持获取 5.3.x 安全补丁
